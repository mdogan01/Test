# Test — Görev Listesi

Saf HTML, CSS ve JavaScript ile yazılmış basit bir görev listesi (to-do) web uygulaması. Herhangi bir derleme adımı veya bağımlılık gerektirmez.

## Özellikler

- Görev ekleme, tamamlandı olarak işaretleme ve silme
- Tümü / Aktif / Tamamlanan filtreleri
- Tamamlanan görevleri tek tıkla temizleme
- Görevler tarayıcıda (`localStorage`) saklanır
- Açık / koyu tema
- Mobil uyumlu tasarım

## Çalıştırma

`index.html` dosyasını tarayıcıda açmanız yeterli. Ya da yerel bir sunucuyla:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Dosya yapısı

```
index.html   # Sayfa yapısı
style.css    # Stiller ve temalar
app.js       # Uygulama mantığı
```
